Research Methodology

The diagnostic instrument utilizes a hybrid NLP/ML pipeline where the spaCy library performs linguistic tokenization and entity extraction. The core classification logic is driven by a TfidfVectorizer and a LogisticRegression model, mapping user-reported symptoms to established health protocols. System effectiveness is verified through real-time telemetry, tracking the stability of the machine learning model outputs against secondary analysis trends to ensure high-fidelity classification and reliable preliminary assessments.

Analysis Objective

The primary objective is to validate the prototype's performance across three key domains: Diagnostic Accuracy (NLP/ML success rate), Response Latency (computational efficiency of the Python/Flask backend), and Referral Correctness (mathematical verification of the Leaflet-based geospatial mapping). By cross-referencing live user coordinates with the hospital database, this analysis ensures the instrument effectively directs users to accredited healthcare facilities, validating both system usability and clinical utility.

Scientific Integrity & Instrument Validity

To maintain academic rigor, this dashboard provides a technical validation of the AI logic. The integrity of the system is measured by comparing the spaCy-informed classification against standard medical diagnostic protocols. This ensures the instrument measures what it was intended to measure: accurate preliminary assessments and reliable geographic mapping. Access is restricted to authorized personnel to protect the telemetry data used in the final research dissertation.
